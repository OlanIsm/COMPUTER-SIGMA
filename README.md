# ⚡ COMPUTER SIGMA (compsig)

> Web memory capsule, blog & portfolio circle **COMPUTER SIGMA** (12 Mahasiswa Computer Science BINUS).

---

## 🎮 Fitur Utama
1. **Main Hub (`/`)**: Overview circle, visi, milestone, dan kenangan 1 tahun menjelang kelulusan.
2. **Game Character Selector (`/members`)**:
   - Vibe game roster selection screen.
   - Kartu center 3D perspective dengan depth & dynamic theme glow.
   - Text floating stats di luar sisi kiri dan kanan kartu.
   - Auto-rolling tiap 2 detik (auto-pause on hover/manual control).
   - Klik kartu untuk navigate ke halaman individual member.
3. **Modular Sub-Member Zones (`/members/[slug]`)**:
   - 12 sandbox folder terisolasi (`src/member-zones/`) untuk masing-masing member.
   - 12 developer bisa ngoding secara paralel tanpa resiko git merge conflict.

---

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, Turbopack, TypeScript)
- **Styling:** Tailwind CSS
- **Animation Engine:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel
